# Roadmap

  on, not one pool.

## Built

- Project overview: a project's page lists every task in it, grouped by
  state (Needs attention, Running, Finished, Ended), so the page
  answers "what is going on in this project" without the Tasks page.
- Projects: create, edit and delete; tasks start with the project's
  defaults (docs/adr/0009-projects.md).
- Dismissing finished tasks (docs/adr/0011-dismissing-finished-tasks.md).
