# REQ-0160 A classed vessel's overhaul dates come from its status report

Status: accepted

For a classed vessel, each engine is due for overhaul on the date the
society's latest status report gives for it. REQ-0117, REQ-0118, REQ-0119,
REQ-0121 and REQ-0122 do not apply to a classed vessel.

## Rationale
Class scheme notice §3.
