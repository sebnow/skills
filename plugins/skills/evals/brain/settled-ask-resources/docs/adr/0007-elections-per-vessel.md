# Elections are made per vessel

## Context

An operator who runs more than one vessel may need a different option on
the same clause for each: deferring the survey on an older workboat but not
on a new one. Today an election belongs to the operator and covers every
vessel they run.

## Outcome

An election is about one vessel and one clause. The operator names the
vessel when electing. A vessel's elections apply only to that vessel's
return.

An election may carry a document as evidence.

## Consequences

- `tidewright elect` takes the vessel.
- Two vessels of one operator can be under different options on the same
  clause in the same season.
