# Guidance: filing operating returns online (2027 season)

Issued by the Authority to operators and to the makers of filing tools.

1. From the 2027 season an operator may file the operating return online.
2. A return filed online is filed with every document a figure in it rests
   on. The Authority does not fetch documents on the operator's behalf.
3. The Authority may re-run the filing tool on the documents filed and the
   tool's version. A return it cannot reproduce from them is rejected.
4. A filing tool may read a document from the network when the operator
   records it. It may not read one while it produces the return.
5. The regulation text a return applies is the text the Authority publishes
   for the season, with the amendments in force on 1 April of that season.
